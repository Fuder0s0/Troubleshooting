OBJETO

ATIVIDADES GERAIS
Programação de Sistemas de Informações através de atividades técnicas necessárias ao desenvolvimento
de sistemas computacional, Entre as principais atividades destacam-se, codificação em linguagem de
programação, realização de testes e documentação das implementações.
Manutenção corretiva através de alteração de código-fonte com o objetivo de disponibilizar
funcionalidades parcial ou totalmente indisponível e/ou incompatibilidade do sistema com os demais
componentes de software ou hardware existentes no ambiente onde é executado.
Manutenção Evolutiva através de alterações de código-fonte realizada nos sistemas, com o objetivo de
disponibilizar novas funcionalidades devido a alterações de requisitos, adequação a novas necessidades
do usuário e/ou adaptações necessárias para permitir o funcionamento do sistema com outras versões de
software de apoio, linguagem de programação ou sistema de gerenciamento de banco de dados.
 
ATIVIDADES ESPECÍFICAS PROGRAMADORES .NET/ASP
Serviços de manutenção corretiva e evolutiva em sistemas existentes utilizando a plataforma .Net com
linguagem C# em aplicações cliente/servidor e web, bem como a linguagem de banco de dados Transact-
SQL com SGBD Microsoft SQL Server 2012 ou superior.
Serviços de manutenção corretiva e evolutiva em sistemas ASP existentes utilizando as linguagens de
programação VBScript, JavaScript e linguagem de banco de dados Transact-SQL com SGBD Microsoft
SQL Server 2012 ou superior.
Verificação do funcionamento dos sistemas e portais, bem como o cumprimento dos requisitos,
funcionalidades e comportamentos especificados. Inclui a busca por defeitos e falhas de implementação
e/ou especificação visando garantir a funcionalidade, confiabilidade, usabilidade, eficiência,
manutenibilidade e portabilidade dos sistemas e portais.
