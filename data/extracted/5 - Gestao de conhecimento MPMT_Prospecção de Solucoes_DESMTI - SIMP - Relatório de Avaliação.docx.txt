Relatório dos Componentes do Sistema SIMP (MPMT):

O sistema SIMP (MPMT) é composto por diversas partes interconectadas, que podem ser agrupadas nas seguintes categorias:

1. Módulos Principais e Adjacentes:

Esta seção representa as funcionalidades centrais e os módulos de apoio do sistema.

EJ Cível (Execução Judicial Cível): Módulo responsável pela gestão dos processos de execução judicial na área cível.

Gabinete Virtual: Ferramenta para o trabalho virtual dos gabinetes dos magistrados.

Protocolo Virtual (CARD): Sistema para registro e controle eletrônico de documentos e processos.

EJ Criminal (Execução Judicial Criminal): Módulo para a gestão dos processos de execução penal na área criminal.

Assistente IA: Indica a presença de um assistente baseado em Inteligência Artificial para auxiliar em tarefas.

Distribuição: Módulo para a distribuição eletrônica de processos.

JUD Cível (Judicial Cível): Módulo principal para a tramitação de processos judiciais na área cível.

Configuração de Fluxos: Ferramenta para a definição e gerenciamento dos fluxos de trabalho dentro do sistema.

T. Eletrônica (Tramitação Eletrônica): Refere-se à funcionalidade de tramitação de processos de forma eletrônica.

PROC JUD (Processo Judicial): Módulo genérico para a gestão de processos judiciais.

Inquéritos: Módulo específico para a gestão de inquéritos policiais.

JUD Criminal (Judicial Criminal): Módulo principal para a tramitação de processos judiciais na área criminal.

Relatórios: Funcionalidade para geração de relatórios diversos sobre os processos e atividades do sistema.

Corregedoria: Módulo relacionado às atividades da corregedoria.

PROC EXE PEN (Processo de Execução Penal) - MNI CNJ: Módulo para a gestão dos processos de execução penal, integrado ao MNI (Monitoramento Nacional de Indicadores) do CNJ (Conselho Nacional de Justiça).

Controle de Prazos: Funcionalidade para o monitoramento e controle dos prazos processuais.

PROC ELEITORAL - MNI TRE: Módulo para a gestão dos processos eleitorais, integrado ao MNI do TRE (Tribunal Regional Eleitoral).

Eleitoral: Módulo principal para a tramitação de processos na área eleitoral.

Sistemas Externos (que interagem com o SIMP):

PJC - (Sistema GEIA): Indica uma integração com o sistema GEIA da Polícia Judiciária Civil.

TJMT: Tribunal de Justiça de Mato Grosso (origem ou destino de informações/processos).

SEEU CNJ: Sistema Eletrônico de Execução Unificada do Conselho Nacional de Justiça.

PJE TRE: Processo Judicial Eletrônico dos Tribunais Regionais Eleitorais.

APFD: Auto de Prisão em Flagrante Delito (possível integração para recebimento de informações).

2. Integrações com Sistemas Internos:

Esta seção lista outros sistemas internos que se integram com o SIMP para troca de dados e funcionalidades.

Procuradoria Virtual: Ferramenta virtual para as atividades da procuradoria.

Banco de Projetos (BAPRE): Sistema para gestão de projetos.

Tabelas Gerais: Refere-se a tabelas de dados utilizadas pelo sistema.

Serviço de Relatório: Serviço interno para geração de relatórios específicos.

SISPLAN: Sistema de planejamento.

Massif (Gestão de usuários): Sistema para gestão de usuários e suas permissões.

Serviço de BI (Business Intelligence) - Data Lake/Datena: Serviço de inteligência de negócios utilizando um Data Lake (repositório de dados) e possivelmente a ferramenta Datena.

Hermes (Notificações): Sistema para envio e gestão de notificações eletrônicas.

ESCRITA (Manuscritos): Possível sistema para gestão de documentos manuscritos ou digitalizados.

JMLC (Laudos e investigações): Sistema para gestão de laudos e informações de investigações.

3. Serviços de Infraestrutura, Componentes & Serviços Externos:

Esta seção descreve a infraestrutura de TI, componentes de hardware/software e serviços externos que suportam o funcionamento do SIMP.

Assinatura Digital SERV: Serviço de assinatura digital.

Mini Storage: Solução de armazenamento de dados de menor escala.

Outros provedores de armazenamento importantes: Indica a utilização de outros serviços de armazenamento relevantes.

Google GEMINI: Possível integração ou utilização de serviços do Google Gemini (uma IA conversacional).

Diversas rotinas em batch (COMPLEMENTO ao sistema): Execução de tarefas automatizadas em lote para complementar o sistema.

Workstation com NVIDIA RTX 2080: Estações de trabalho com placas gráficas NVIDIA RTX 2080, sugerindo o uso de aplicações que exigem poder de processamento gráfico.

HELP DESK (COMPLEMENTO): Serviço de suporte técnico para o sistema.

BAMBOO (BUILD): Ferramenta de integração contínua e entrega contínua (CI/CD) para a construção e implantação do sistema.

Atlassian Confluence Management: Utilização do Confluence da Atlassian para gestão do conhecimento e colaboração.

SOBRE O PROJETO SISTEMA ÚNICO

O Objetivo do projeto SISTEMA ÚNICO é viabilizar uma única plataforma de trabalho para atuação finalística do MPPE de modo que todas as capacidades de negócio estejam disponíveis por meio de um único sistema de informação, minimizando a utilização de sistemas satélites ou paralelos.

Ao longo dos últimos 20 anos, o MPPE pôde observar diversas mudanças em sua forma de trabalhar e nos sistemas disponíveis para realização do trabalho. Por questões de natureza técnica, estratégia de trabalho ou indisponibilidade de recursos humanos e financeiros, não foi possível à CMTI viabilizar um único sistema.

Atualmente, o MPPE utiliza os seguintes serviços de TI: ARQUIMEDES, SIM, CONSENSUS, PJE JUDICIAL, PJE ELEITORAL, SISTEMA DE EXECUÇÕES PENAIS (SEEU).

Esta problemática é pertinente a todas as unidades do MP brasileiro, sobretudo após os recentes avanços na tecnologia de nuvem, na possibilidade de utilização de IA, na melhoria das capacidades de tramitação do INQUÉRITO POLICIAL e do PROCESSO JUDICIAL de modo totalmente eletrônico, além da própria maturidade das unidades do MP brasileiro.

Considerando a estratégia institucional para viabilização de sistema unificado com foco na qualidade de trabalho dos membros e servidores, integração dos fluxos de dados de ponta a ponta, aumento da eficiência operacional… entende-se que a utilização de plataforma de trabalho unificada e integrada é fundamental para o alcance desta estratégia. 

O projeto SISTEMA ÚNICO visa consolidar as funcionalidades essenciais do MPPE em uma plataforma unificada, dispensando o uso de sistemas paralelos. Esta questão é relevante para todo o MP brasileiro, impulsionada pelos avanços em nuvem, IA, tramitação eletrônica do Inquérito Policial e Processo Judicial, e pela evolução das unidades do MP. Em consonância com a estratégia institucional de implementar um sistema único focado na qualidade do trabalho, integração de dados e eficiência operacional, a adoção de uma plataforma unificada e integrada é crucial.
